Queries

Home › Programming Introduction

Add a question mark (?) to the end of a command to query the current setting or measurement result. A query returns an ASCII string.

Return Types

TypeDescription
ASCII integerDecimal integer; boolean values are returned as 1 / 0
ASCII floatDecimal floating-point number, possibly in scientific notation
ASCII enumeration stringReturns the option keyword (short form), e.g. MIN
ASCII comma-separated stringMultiple values separated by commas (e.g. the *IDN? response)

VSET? Queries

Some commands support the :VSET? suffix, which returns the comma-separated list of all values currently available for that parameter. For example:

:CHANnel1A:FSELect:RATe:VSET?
