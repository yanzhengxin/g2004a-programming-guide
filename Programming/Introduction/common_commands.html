IEEE 488.2 Common Commands

Home › Programming Introduction

Common commands begin with an asterisk (*), follow the IEEE 488.2 standard, and are independent of the SCPI subsystems. The G2004A supports the following common commands:

CommandDescription
*IDN?Returns the instrument identification string (manufacturer, model, serial number, firmware version)
*OPC?Returns 1 after prior operations complete (blocking synchronization)

The G2004A *IDN? response format is:

GoLight,G2004A,XXXXXXXXX,V1.0.0.1
