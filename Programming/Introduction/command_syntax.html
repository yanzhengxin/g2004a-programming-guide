Command Syntax Conventions

Home › Programming Introduction

This guide uses the following notation conventions when describing commands:

SymbolMeaningExample
< >Required parameter (replace the text inside with a value or string)<gain>
{ }Enumeration parameter; the braces enclose the choices{ON | OFF | 1 | 0}
|Separates mutually exclusive choicesON | OFF
1 / A|B|C|DChannel slot number / channel letter range (inside braces)CHANnel{1}{A|B|C|D}
?Query suffix that turns a setting command into a query:DISPlay?
Uppercase lettersShort form keyword (the full form includes the lowercase part)DISPlay = DISP

Example

:CHANnel1A:TRANsducer:GAIN 2.000

Sets the external transducer gain of channel 1A to 2.000.
