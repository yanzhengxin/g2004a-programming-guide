SCPI (Standard Commands for Programmable Instruments) defines a standardized syntax for controlling test and measurement instruments. The G2004A command set follows the SCPI standard.

Command Tree Structure

SCPI commands use a tree structure, with keywords separated by colons (:). For example:

:CHANnel{1}{A|B|C|D}:DISPlay {ON | OFF | 1 | 0}

Here CHANnel is the root keyword (subsystem), and DISPlay is the leaf keyword.

Long Form and Short Form

SCPI keywords are case-insensitive. Uppercase letters indicate the short form; the lowercase letters complete the long form. For example, DISPlay can be written as DISP, and both are equivalent.

Command Types

  • Setting commands: set an instrument parameter, e.g. :CHANnel1A:DISPlay ON.
  • Query commands: end with a question mark (?) and return the current setting or measurement, e.g. :CHANnel1A:DISPlay?.
