Query Syntax

*IDN?

Description

Returns an ASCII string that lists the DCA-M model number G2004, the DCA-M's serial number, and DCA-M's firmware version. This is shown in the following example,
"GoLight,G2004,XXXXXXXXX,V1.0.0.1"

Return Value

Return TypeASCII comma-separated string (str)
Typical Return ValueGoLight,G2004A,XXXXXXXXX,V1.0.0.1
