Command Syntax

:TRIGger:PLENgth <symbols>

Query Syntax

:TRIGger:PLENgth?

Description

Enters the length of the test pattern in symbols, which is used in pattern lock trigger mode.

Parameters

<symbols>

Return Value

Return TypeASCII integer (int)
Typical Return Value65535
