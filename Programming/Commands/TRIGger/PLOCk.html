:TRIGger:PLOCk

Home › Command Reference › TRIGger Subsystem

Command Syntax

:TRIGger:PLOCk {ON | OFF | 1 | 0}

Query Syntax

:TRIGger:PLOCk?

Description

Turns on or off pattern locking, which generates a pattern trigger.

Parameters

{ON | OFF | 1 | 0}

Return Value

Return TypeASCII integer (int, boolean)
Typical Return Value1 (on) or 0 (off)
