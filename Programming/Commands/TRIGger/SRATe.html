:TRIGger:SRATe

Home › Command Reference › TRIGger Subsystem

Command Syntax

:TRIGger:SRATe <symbol rate>

Query Syntax

:TRIGger:SRATe?

Description

When using pattern lock use this command to enter or read the symbol rate of the trigger source.

Parameters

<symbol rate>

Return Value

Return TypeASCII float
Typical Return Value1.0625E+11
