:MEASure:EYE:PAM:EWIDth:SOURce

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:EWIDth:SOURce {CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Query Syntax

:MEASure:EYE:PAM:EWIDth:SOURce?

Description

Selects the source waveform on which to perform the EWidth measurement for PAM4 signals. The source must be an eye diagram..

Parameters

{CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Return Value

Return TypeASCII waveform source string (str)
Typical Return ValueFUNC1
