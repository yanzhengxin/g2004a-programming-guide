Command Syntax

:MEASure:EYE:PAM:EWIDth

Query Syntax

:MEASure:EYE:PAM:EWIDth?

Description

Returns Eye mode's PAM4 Eye Width measurement. Eye Width measures the horizontal opening for the selected eye of a PAM signal. Select the eye measurement to be returned using the :MEASure:EYE:PAM:EYE child command. To measure the eye width for all of the eyes on a PAM signal, you must send this command once for each eye as there is no command for simultaneously measuring all eyes.

Return Value

Return TypeASCII float (s)
Typical Return Value2.50E-11
