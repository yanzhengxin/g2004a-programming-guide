:MEASure:PAM:EYE:TIME:UNITs

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:PAM:EYE:TIME:UNITs {SECond | UINTerval}

Description

Sets the time units for PAM4 width and skew measurements. The units can be seconds (SECond) or unit interval (UINTerval).
The following measurements are affected by this setting:

EyeMode
• PAM Level Skews (:EYE:PAM:SKEW)
• PAM Eye Skews (:EYE:PAM:ESKew)
• PAM Eye Widths (:EYE:PAM:EWIDth)

Unit Conversion

The SECond and UINTerval settings express the same measurement in two different units, related by the symbol (baud) rate:

1 UI = 1 / baud rate
time (s) = UI x (1 / baud rate)
UI = time (s) x baud rate

For a 106.5625 GBd PAM4 signal:

1 UI = 1 / 106.5625 x 10^9 s = 9.384 ps
UITime (ps)
0.25 UI2.346 ps
0.50 UI4.692 ps
0.75 UI7.038 ps
1.00 UI9.384 ps

To convert between the two units:

UI -> ps: multiply by 9.384
ps -> UI: divide by 9.384
