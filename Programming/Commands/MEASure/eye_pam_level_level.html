:MEASure:EYE:PAM:LEVel:LEVel

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:LEVel:LEVel LEVel{0:3}

Query Syntax

:MEASure:EYE:PAM:LEVel:LEVel?

Description

Selects the PAM4 eye diagram's level on which to perform the :MEASure:EYE:PAM:LEVel measurement.

Parameters

LEVel{0:3}

:MEASure:EYE:LIST:CLEar
