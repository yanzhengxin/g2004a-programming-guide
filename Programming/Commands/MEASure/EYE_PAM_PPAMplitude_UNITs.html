:MEASure:EYE:PAM:PPAMplitude:UNITs

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:PPAMplitude:UNITs {WATT | DBM | VOLT}

Query Syntax

:MEASure:EYE:PAM:PPAMplitude:UNITs?

Description

Sets the amplitude units for the Transmitter Power Excursion measurement (:MEASure:EYE:PAM:TPEXcursion). Units can be Watts (WATT) or dBM (DBM).

Parameters

{WATT | DBM | VOLT}

Return Value

Return TypeASCII enumeration string (str)
Typical Return Value{WATT | DBM | VOLT}
