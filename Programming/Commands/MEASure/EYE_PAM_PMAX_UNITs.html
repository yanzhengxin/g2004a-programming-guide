:MEASure:EYE:PAM:PMAX:UNITs

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:PMAX:UNITs {WATT | DBM}

Query Syntax

:MEASure:EYE:PAM:PMAX:UNITs?

Description

Sets the amplitude units for the Pk-Pk Amplitude measurement (:MEASure:EYE:PAM:PMAX). Units can be Watts (WATT) or dBM (DBM).

Parameters

{WATT | DBM}

Return Value

Return TypeASCII enumeration string (str)
Typical Return Value{WATT | DBM}
