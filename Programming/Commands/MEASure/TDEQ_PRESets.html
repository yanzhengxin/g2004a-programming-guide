:MEASure:TDEQ:PRESets

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:TDEQ:PRESets <preset name>

Query Syntax

:MEASure:TDEQ:PRESets?

Description

Loads a preset for a TDECQ measurement (:MEASure:EYE:TDECQ). The preset configures the measurement to the proper settings. To query which presets are available for loading, use the MEASure:TDEQ:PRESets:SELections? query
TDECQ Measurement Presets
◆ IEEE 802.3dj Draft 2.3 DR (500m)
◆ IEEE 802.3dj Draft 2.3 DR (2km)
◆ IEEE 802.3bs

Parameters

<preset name>
