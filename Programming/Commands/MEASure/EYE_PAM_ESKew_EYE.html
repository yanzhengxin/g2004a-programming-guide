:MEASure:EYE:PAM:ESKew:EYE

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:ESKew:EYE EYE{0:2}

Query Syntax

:MEASure:EYE:PAM:ESKew:EYE?

Description

This command allows you to select an eye on PAM4 signals on which to perform the :MEASure:EYE:PAM:ESKew measurement.

Parameters

EYE{0:2}
