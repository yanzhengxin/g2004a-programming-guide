:MEASure:EYE:PAM:VECLosure:EYE

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:VECLosure:EYE EYE{0:2}

Query Syntax

:MEASure:EYE:PAM:VECLosure:EYE?

Description

This command allows you to select an eye on PAM4 signals. This command selects the PAM eye on which to perform the :MEASure:EYE:PAM:VECLosure. The query form of the command returns the currently selected eye.

Parameters

EYE{0:2}

Return Value

Return TypeASCII enumeration string (str)
Typical Return Value{EYE0 | EYE1 | EYE2}
