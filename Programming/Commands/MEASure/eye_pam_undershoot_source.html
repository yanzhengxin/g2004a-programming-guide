:MEASure:EYE:PAM:UNDershoot:SOURce

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:UNDershoot:SOURce {CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Query Syntax

:MEASure:EYE:PAM:UNDershoot:SOURce?

Description

Selects the source waveform on which to perform the :MEASure:EYE:PAM:UNDershoot measurement.

Parameters

{CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Return Value

Return TypeASCII waveform source string (str)
Typical Return ValueFUNC1

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:PAM:UNDershoot:SOURce FUNC2
:MEASure:EYE:PAM:UNDershoot
:MEASure:EYE:PAM:UNDershoot?
