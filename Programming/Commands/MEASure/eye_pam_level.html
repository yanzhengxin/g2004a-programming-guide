:MEASure:EYE:PAM:LEVel

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:LEVel

Query Syntax

:MEASure:EYE:PAM:LEVel?

Description

In Eye mode, measures all four amplitude levels of a PAM4 eye diagram.

Return Value

Return TypeASCII float (amplitude unit follows source)
Typical Return Value3.30E-1

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:PAM:LEVel:SOURce FUNC2
