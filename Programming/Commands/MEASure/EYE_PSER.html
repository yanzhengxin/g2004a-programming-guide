Command Syntax

:MEASure:EYE:PSER

Query Syntax

:MEASure:EYE:PSER?

Description

Performs a Partial SER measurement on a PAM4 waveform. The Partial SER measurement measures the target Symbol Error Rate (SER) that is calculated and used in a TDECQ measurement

Return Value

Return TypeASCII float (scientific notation)
Typical Return Value1.00E-6
