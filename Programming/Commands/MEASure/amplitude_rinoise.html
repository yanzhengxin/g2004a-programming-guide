:MEASure:AMPLitude:RINoise

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:AMPLitude:RINoise

Query Syntax

:MEASure:AMPLitude:RINoise?

Description

RIN is a measure of the noise-to-signal ratio of an optical source. The query form of the command returns the Relative Intensity Noise (RIN) measurement of optical signals measured value

Return Value

Return TypeASCII float (dB/Hz)
Typical Return Value-140.0

Programming Example

; ============================================
; G2004A - :MEASure:AMPLitude:RINoise Test Script
; ============================================
; --- Step 1: Clear measurement list ---
:MEASure:EYE:LIST:CLEar
; --- Step 2: Configure RIN measurement source ---
:MEASure:AMPLitude:RINoise:SOURce CHAN1B
; --- Step 3: Execute RIN measurement ---
:MEASure:AMPLitude:RINoise
; --- Step 4: Query measurement result ---
:MEASure:AMPLitude:RINoise?
; Expected: ASCII float (dB/Hz), e.g. -140.0
; --- Step 5: Verify current source configuration (optional) ---
:MEASure:AMPLitude:RINoise:SOURce?
; Expected: CHAN1B
