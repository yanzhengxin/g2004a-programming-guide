:MEASure:EYE:PAM:OVERshoot

Command Syntax

:MEASure:EYE:PAM:OVERshoot

Query Syntax

:MEASure:EYE:PAM:OVERshoot?

Description

Moves the PAM4 Overshoot measurement to the top of the Eye Mode Results measurement results.

Return Value

Return TypeASCII float (%)
Typical Return Value2.0

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:PAM:OVERshoot:SOURce FUNC2
:MEASure:EYE:PAM:OVERshoot
:MEASure:EYE:PAM:OVERshoot?
