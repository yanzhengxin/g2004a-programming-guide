:MEASure:EYE:NMARgin

Command Syntax

:MEASure:EYE:NMARgin

Query Syntax

:MEASure:EYE:NMARgin?

Description

The Noise Margin (rms) measurement measures the electrical output of an O/E receiver. The Noise Margin(rms) measurement includes the contribution of all three PAM4 waveform eyes. This differs from a Partial Noise Margin measurement (:MEASure:EYE:PNMargin) that is based on the contribution of a single PAM4 eye. Noise margin is a system-level test that measures the amount of noise power that can be added to a system while maintaining its performance at a specific Symbol Error Rate (SER) at the output of an O/E receiver.

Return Value

Return TypeASCII float (%)
Typical Return Value8.0
