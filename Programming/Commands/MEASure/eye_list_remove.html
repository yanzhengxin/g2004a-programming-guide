:MEASure:EYE:LIST:REMove

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:LIST:REMove <index>

Description

Delete the test item at the specified index from the result table.

Parameters

<index>

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:APOWer
:MEASure:EYE:CTDecq
:MEASure:EYE:CNMargin
:MEASure:EYE:LIST:SELect 3
:MEASure:EYE:LIST:REMove 3
:MEASure:EYE:LIST:SELect 1
:MEASure:EYE:LIST:REMove 1
