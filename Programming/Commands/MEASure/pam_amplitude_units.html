:MEASure:PAM:AMPLitude:UNITs

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:PAM:AMPLitude:UNITs {AMPLitude | PERCent}

Description

Sets the amplitude units for PAM4 level and level RMS (thickness) measurements.
The following measurements are affected by this setting:

Eye Mode
• PAM Levels (:EYE:PAM:LEVel)
• PAM Levels RMS (:EYE:PAM:RMS)
• PAM Eye Levels (:EYE:PAM:ELEVel)
• PAM Eye Heights (:EYE:PAM:EHeight)

Unit Conversion

The AMPLitude and PERCent settings express the same measurement in two different units. AMPLitude is an absolute value (volts for electrical, watts for optical), while PERCent is the value normalized to the full PAM4 signal swing:

PERCent (%) = (AMPLitude / full signal swing) x 100
AMPLitude = PERCent (%) x full signal swing / 100

where the full signal swing is the peak-to-peak amplitude of the entire PAM4 signal (highest level minus lowest level).

For an electrical PAM4 signal with a 1 V full swing and equal level spacing:

Level / MeasurementAMPLitude (V)PERCent (%)
L0 (lowest level)0.000 V0%
L10.333 V33.3%
L20.667 V66.7%
L3 (highest level)1.000 V100%
Eye height0.333 V33.3%

To convert between the two units:

AMPLitude -> PERCent: divide by full swing, multiply by 100
PERCent -> AMPLitude: multiply by full swing, divide by 100

Note: For an optical signal, AMPLitude is in watts (W). The PERCent value is always relative to the full signal swing, not to a single eye height — with equal PAM4 level spacing, one eye height is about 33.3% of the full swing.

Parameters

{AMPLitude | PERCent}
