:MEASure:EYE:PSER:SIDe

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PSER:SIDe {LEFT | RIGHt}

Query Syntax

:MEASure:EYE:PSER:SIDe?

Description

Selects the side of the waveform on which to perform a Partial SER measurement (:MEASure:EYE:PSER). The default setting is LEFT.

Parameters

{LEFT | RIGHt}

Return Value

Return TypeASCII enumeration string (str)
Typical Return Value{LEFT | RIGH}
