:MEASure:EYE:PNMargin:EYE

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PNMargin:EYE {EYE0 | EYE1 | EYE2}

Query Syntax

:MEASure:EYE:PNMargin:EYE?

Description

This command allows you to select an eye on PAM4 signal for a Partial Noise Margin measurement (:MEASure:EYE:PNMARgin) measurement. The default setting is EYE0.

Parameters

{EYE0 | EYE1 | EYE2}

Return Value

Return TypeASCII enumeration string (str)
Typical Return Value{EYE0 | EYE1 | EYE2}
