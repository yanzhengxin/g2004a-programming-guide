Command Syntax

:MEASure:AMPLitude:RINoise

Query Syntax

:MEASure:AMPLitude:RINoise?

Description

RIN is a measure of the noise-to-signal ratio of an optical source. The query form of the command returns the Relative Intensity Noise (RIN) measurement of optical signals measured value

Return Value

Return TypeASCII float (dB/Hz)
Typical Return Value-140.0
