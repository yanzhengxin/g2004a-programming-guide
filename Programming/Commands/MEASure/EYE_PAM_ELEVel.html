:MEASure:EYE:PAM:ELEVel

Command Syntax

:MEASure:EYE:PAM:ELEVel

Query Syntax

:MEASure:EYE:PAM:ELEVel?

Description

Starts Eye mode's Eye PAM4 Level measurement where the center amplitude of the selected eye (vertical center) of a PAM signal is measured. Select the eye to be measured using the :MEASure:EYE:PAM:ELEVel:EYE child command. To measure the eye levels for all of the eyes on a PAM4 signal, you must send this command once for each eye as there is no command for simultaneously measuring all eye levels. The query form of the command returns the measured value.

Return Value

Return TypeASCII float (V)
Typical Return Value1.50E-1
