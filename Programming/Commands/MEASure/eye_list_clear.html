Command Syntax

:MEASure:EYE:LIST:CLEar

Description

Clear all active eye measurement items in the result table.

Programming Example

:MEASure:EYE:CTDecq
:MEASure:EYE:CNMargin
:MEASure:EYE:LIST:CLEar
