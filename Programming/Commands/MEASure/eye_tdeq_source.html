Query Syntax

Description

Selects the source waveform on which to perform the TDEQ measurement.

Parameters

{CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Return Value

Return TypeASCII waveform source string (str)
Typical Return ValueFUNC1

:MEASure:EYE:TDEQ
