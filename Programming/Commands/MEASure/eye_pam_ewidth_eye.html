:MEASure:EYE:PAM:EWIDth:EYE

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:EWIDth:EYE EYE{0:2}

Query Syntax

:MEASure:EYE:PAM:EWIDth:EYE?

Description

This command allows you to select an eye on PAM4 signals on which to perform the :MEASure:EYE:PAM:EWIDth measurement.

Parameters

EYE{0:2}

Return Value

Typical Return Value{EYE0 | EYE1 | EYE2}

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:PAM:EWIDth:SOURce FUNC1
:MEASure:EYE:PAM:EWIDth:DEFine:EOPening PROBability
:MEASure:EYE:PAM:EWIDth:DEFine:EOPening?
