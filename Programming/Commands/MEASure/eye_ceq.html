:MEASure:EYE:CEQ

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:CEQ

Query Syntax

:MEASure:EYE:CEQ?

Description

The Eye mode PAM Ceq measurement measures the noise gain introduced by the DFE and CTLE Waveform Signal Processing operators.

Return Value

Return TypeASCII float (dB)
Typical Return Value2.1

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:CEQ:SOURce FUNC2
:MEASure:EYE:CEQ
:MEASure:EYE:CEQ?
