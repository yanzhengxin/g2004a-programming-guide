Command Syntax

:MEASure:EYE:PAM:LINearity:DEFinition {RLMA120 | RLMC94 | EYE}

Query Syntax

:MEASure:EYE:PAM:LINearity:DEFinition?

Description

Selects the algorithm used to measure RML (Ratio Level Mismatch) linearity on a PAM signal in Eye mode.

Parameters

{RLMA120 | RLMC94 | EYE}

Return Value

Return TypeASCII enumeration string (str)
Typical Return ValueRLMA120
