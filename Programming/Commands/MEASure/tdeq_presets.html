:MEASure:TDEQ:PRESets

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:TDEQ:PRESets <preset name>

Query Syntax

:MEASure:TDEQ:PRESets?

Description

Loads a preset for a TDECQ measurement (:MEASure:EYE:TDECQ). The preset configures the measurement to the proper settings. To query which presets are available for loading, use the MEASure:TDEQ:PRESets:SELections? query

TDECQ Measurement Presets

The :MEASure:TDEQ:PRESets command loads a saved preset that configures the TDECQ measurement (:MEASure:EYE:TDEQ). A preset sets the two measurement parameters defined by the target standard: the histogram width (:MEASure:TDEQ:HWIDth) and the target symbol error ratio (:MEASure:TDEQ:TSER). The reference equalizer (receiver bandwidth and FFE taps) is configured separately with :SPRocess:TEQualizer:PRESets.

The 802.3dj presets are split by reach because the histogram width and target SER are tuned per PMD. DR (parallel single-mode fiber) and FR4 / LR4 (4-wavelength CWDM) operate over different distances (500 m, 2 km, 10 km), which introduce different amounts of chromatic dispersion. Select the preset that matches the reach of the transmitter under test.
