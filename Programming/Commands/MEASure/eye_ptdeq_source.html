:MEASure:EYE:PTDeq:SOURce

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PTDeq:SOURce {CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Query Syntax

:MEASure:EYE:PTDeq:SOURce?

Description

Selects the source waveform on which to perform a Partial TDECQ measurement (:MEASure:EYE:PTDeq).

Parameters

{CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Return Value

Return TypeASCII waveform source string (str)
Typical Return ValueFUNC1
