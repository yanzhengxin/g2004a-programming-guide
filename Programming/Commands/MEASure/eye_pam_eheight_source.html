:MEASure:EYE:PAM:EHEight:SOURce

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:EHEight:SOURce {CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Query Syntax

:MEASure:EYE:PAM:EHEight:SOURce?

Description

Selects the source waveform on which to perform the EHEight measurement for PAM4 signals. The source must be an eye diagram.

Parameters

{CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Return Value

Return TypeASCII waveform source string (str)
Typical Return ValueFUNC1
