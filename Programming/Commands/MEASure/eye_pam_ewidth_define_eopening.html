:MEASure:EYE:PAM:EWIDth:DEFine:EOPening

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:EWIDth:DEFine:EOPening {PROBability}

Query Syntax

:MEASure:EYE:PAM:EWIDth:DEFine:EOPening?

Description

Selects the method used to determine the eye-opening: probability (PROBabilitly).

Parameters

{PROBability}

Return Value

Return TypeASCII enumeration string (str)
Typical Return ValuePROBability
