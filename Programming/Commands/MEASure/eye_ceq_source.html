:MEASure:EYE:CEQ:SOURce

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:CEQ:SOURce {CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Query Syntax

:MEASure:EYE:CEQ:SOURce?

Description

Selects the source waveform on which to perform the :MEASure:EYE:CEQ measurement. The default value is source_waveform.

Parameters

{CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Return Value

Return TypeASCII waveform source string (str)
Typical Return ValueFUNC1

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:CEQ:SOURce FUNC2
:MEASure:EYE:CEQ
:MEASure:EYE:CEQ?
