:MEASure:PAM:EYE:TIME:UNITs

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:PAM:EYE:TIME:UNITs {SECond | UINTerval}

Query Syntax

:MEASure:PAM:EYE:TIME:UNITs?

Description

Sets the time units for PAM4 width and skew measurements. The units can be seconds (SECond) or unit interval (UINTerval).
The following measurements are affected by this setting:

EyeMode
◆PAM Level Skews (:EYE:PAM:SKEW)
◆PAM Eye Skews (:EYE:PAM:ESKew)
◆PAM Eye Widths (:EYE:PAM:EWIDth)

Parameters

{SECond | UINTerval}
