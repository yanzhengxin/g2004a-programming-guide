:MEASure:EYE:NMARgin:SOURce

Command Syntax

:MEASure:EYE:NMARgin:SOURce {CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Query Syntax

:MEASure:EYE:NMARgin:SOURce?

Description

Selects the source waveform on which to perform a Noise Margin (rms) measurement (:MEASure:EYE:NMARgin).

Parameters

{CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Return Value

Return TypeASCII waveform source string (str)
Typical Return ValueFUNC1

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:NMARgin:SOURce FUNC2
:MEASure:EYE:NMARgin
:MEASure:EYE:NMARgin?
