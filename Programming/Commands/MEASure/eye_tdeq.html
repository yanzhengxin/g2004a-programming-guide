:MEASure:EYE:TDEQ

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:TDEQ

Query Syntax

:MEASure:EYE:TDEQ?

Description

Performs a TDECQ measurement (Transmitter and Dispersion Eye Closure for PAM4) in Eye mode.

Return Value

Return TypeASCII float (dB)
Typical Return Value2.5

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:TDEQ:SOURce FUNC1
:MEASure:EYE:TDEQ
:MEASure:EYE:TDEQ?
