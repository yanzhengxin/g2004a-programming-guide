:MEASure:EYE:PNMargin:SOURce

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PNMargin:SOURce {CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Query Syntax

:MEASure:EYE:PNMargin:SOURce?

Description

Selects the source waveform on which to perform a Partial Noise Margin measurement (:MEASure:EYE:PNMargin).

Parameters

{CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Return Value

Return TypeASCII waveform source string (str)
Typical Return ValueFUNC1
