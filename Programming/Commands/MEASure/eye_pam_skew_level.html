:MEASure:EYE:PAM:SKEW:LEVel

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:SKEW:LEVel LEVel{0:3}

Query Syntax

:MEASure:EYE:PAM:SKEW:LEVel?

Description

Selects the eye diagram's level on which to perform the :MEASure:EYE:PAM:SKEW measurement.

Parameters

LEVel{0:3}

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:PAM:SKEW:SOURce FUNC1
