Command Syntax

:MEASure:EYE:PAM:LINearity

Query Syntax

:MEASure:EYE:PAM:LINearity?

Description

Starts Eye mode PAM4 Linearity measurement, which measures the linearity RLM (Ratio Level Mismatch) between all amplitude levels of a PAM4.

Return Value

Return TypeASCII float (dimensionless)
Typical Return Value0.95
