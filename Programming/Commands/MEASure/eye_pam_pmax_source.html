:MEASure:EYE:PAM:PMAX:SOURce

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:PMAX:SOURce {CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Query Syntax

:MEASure:EYE:PAM:PMAX:SOURce?

Description

Selects the source waveform on which to perform the :MEASure:EYE:PAM:PMAX measurement.

Parameters

{CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Return Value

Return TypeASCII waveform source string (str)
Typical Return ValueFUNC1

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:PAM:PMAX:SOURce FUNC2
:MEASure:EYE:PAM:PMAX:UNITs WATT
:MEASure:EYE:PAM:PMAX:UNITs?
:MEASure:EYE:PAM:PMAX
:MEASure:EYE:PAM:PMAX?
