Command Syntax

:MEASure:EYE:PAM:ELEVel:EYE EYE{0:2}

Description

This command allows you to select an eye on PAM4 waveforms on which to perform the :MEASure:EYE:PAM:ELEVel measurement.

Parameters

EYE{0:2}
