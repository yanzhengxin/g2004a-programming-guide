Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:TTIMe

Query Syntax

:MEASure:EYE:TTIMe?

Description

The Eye mode IEEE 802.3cd PAM Transition Time measurement measures the transition time on PAM4 waveforms. The query form of the command returns the selected transition time measured.

Return Value

Return TypeASCII float (s)
Typical Return Value1.20E-11
