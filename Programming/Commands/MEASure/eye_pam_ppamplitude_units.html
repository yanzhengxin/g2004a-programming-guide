:MEASure:EYE:PAM:PPAMplitude:UNITs

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:PPAMplitude:UNITs {WATT | DBM}

Query Syntax

:MEASure:EYE:PAM:PPAMplitude:UNITs?

Description

Sets the amplitude units for the Transmitter Power Excursion measurement (:MEASure:EYE:PAM:TPEXcursion). Units can be Watts (WATT) or dBM (DBM).

Parameters

{WATT | DBM}

Return Value

Return TypeASCII enumeration string (str)
Typical Return Value{WATT | DBM}

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:PAM:PPAMplitude:SOURce1 FUNC2
:MEASure:EYE:PAM:PPAMplitude:UNITs WATT
:MEASure:EYE:PAM:PPAMplitude:UNITs?
:MEASure:EYE:PAM:PPAMplitude
:MEASure:EYE:PAM:PPAMplitude?
:MEASure:EYE:PAM:PPAMplitude:UNITs dBm
:MEASure:EYE:PAM:PPAMplitude:UNITs?
:MEASure:EYE:PAM:PPAMplitude
:MEASure:EYE:PAM:PPAMplitude?
