Query Syntax

:MEASure:LTESt:ACQuire:COUNt?

Description

Use this query to return the current waveforms, patterns, or samples counted when a waveform, pattern, or samples acquisition limit test is enabled

Return Value

Return TypeASCII integer (int)
Typical Return Value<number>

Programming Example

:LTESt:ACQuire:CTYPe:PATTerns 3
:LTESt:ACQuire:CTYPe:PATTerns?
:LTESt:ACQuire:STATe ON
:LTESt:ACQuire:STATe?
:ACQuire:RUN
*OPC?
:MEASure:LTESt:ACQuire:COUNt?
