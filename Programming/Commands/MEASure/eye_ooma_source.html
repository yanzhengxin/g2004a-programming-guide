:MEASure:EYE:OOMA:SOURce

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:OOMA:SOURce {CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Query Syntax

:MEASure:EYE:OOMA:SOURce?

Description

Selects the source waveform on which to perform the OOMA measurement.

Parameters

{CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Return Value

Return TypeASCII waveform source string (str)
Typical Return ValueFUNC1
