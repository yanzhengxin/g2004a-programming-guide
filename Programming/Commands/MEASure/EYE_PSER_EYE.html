:MEASure:EYE:PSER:EYE

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PSER:EYE {EYE0 | EYE1 | EYE2}

Query Syntax

:MEASure:EYE:PSER:EYE?

Description

This command allows you to select an eye on PAM4 signal for a Partial SER measurement (:MEASure:EYE:PSER) measurement.

Parameters

{EYE0 | EYE1 | EYE2}

Return Value

Return TypeASCII enumeration string (str)
Typical Return Value{EYE0 | EYE1 | EYE2}
