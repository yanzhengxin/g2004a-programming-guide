:MEASure:EYE:PNMargin:SIDe

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PNMargin:SIDe {LEFT | RIGHt}

Query Syntax

:MEASure:EYE:PNMargin:SIDe?

Description

Selects the side of the waveform on which to perform the Partial Noise Margin measurement (:MEASure:EYE:PNMARgin). The default setting is LEFT.

Parameters

{LEFT | RIGHt}

Return Value

Return TypeASCII enumeration string (str)
Typical Return Value{LEFT | RIGH}
