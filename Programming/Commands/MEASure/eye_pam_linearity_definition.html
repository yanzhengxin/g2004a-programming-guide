:MEASure:EYE:PAM:LINearity:DEFinition

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:LINearity:DEFinition {RLMA120 | RLMC94 | EYE}

Query Syntax

:MEASure:EYE:PAM:LINearity:DEFinition?

Description

Selects the algorithm used to measure RML (Ratio Level Mismatch) linearity on a PAM signal in Eye mode.

Linearity Definition

The :MEASure:EYE:PAM:LINearity:DEFinition command selects the algorithm used to measure PAM level linearity in Eye mode. Linearity describes how evenly the PAM signal levels are spaced; a value of 1.0 indicates equal separation between all levels.

DefinitionAlgorithmWaveforms
RLMA120RLM (Ratio Level Mismatch), IEEE 802.3 Annex 120DNRZ, PAM4
RLMC94RLM (Ratio Level Mismatch), IEEE 802.3 Clause 94 (default)NRZ, PAM4, PAM6, PAM8
EYEEye Linearity, OIF CEI 4.0NRZ, PAM4, PAM6, PAM8

RLM (Annex 120D) — RLMA120

Based on the four mean signal levels V0–V3, normalized with the mid-range level Vmid = (V0 + V3) / 2, and the effective symbol levels:

ES1 = (V1 - Vmid) / (V0 - Vmid)
ES2 = (V2 - Vmid) / (V3 - Vmid)
RLM = min(3xES1, 3xES2, 2-3xES1, 2-3xES2)

The 2-3xES terms penalize both level compression and over-spacing, making this the most rigorous definition.

RLM (Clause 94) — RLMC94

Based on the smallest of the three eye heights, normalized to one third of the full swing:

RLM = 3 x min(eye heights) / (V3 - V0)

This definition penalizes only the most compressed eye.

Eye Linearity (CEI 4.0) — EYE

The ratio of the minimum to the maximum adjacent-level separation:

Eye linearity = min(dV_low, dV_mid, dV_upp) / max(dV_low, dV_mid, dV_upp)
