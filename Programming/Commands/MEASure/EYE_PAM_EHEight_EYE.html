:MEASure:EYE:PAM:EHEight:EYE

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:EHEight:EYE EYE{0:2}

Query Syntax

:MEASure:EYE:PAM:EHEight:EYE?

Description

This command allows you to select an eye on PAM4 signals on which to perform the :EHEight measurement.

Parameters

EYE{0:2}

Return Value

Return TypeASCII string (str)
Typical Return Value{EYE0 | EYE1 | EYE2}
