:MEASure:EYE:PNMargin

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PNMargin

Query Syntax

:MEASure:EYE:PNMargin?

Description

Turns on the Partial Noise Margin measurement on a PAM4 waveform. The Partial Noise Margin measurement measures the electrical output of an O/E receiver. The partial noise-margin measurement is based on the contribution of a single PAM4 eye.

Return Value

Return TypeASCII float (%)
Typical Return Value6.5
