:MEASure:EYE:OER:UNITs

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:OER:UNITs {DECibel | PERCent | RATio}

Query Syntax

:MEASure:EYE:OER:UNITs?

Description

Set or query the result unit of Outer extinction ratio.

OER Unit Conversion

The :MEASure:EYE:OER:UNITs command selects the units of the Outer Extinction Ratio (OER) measurement. OER is the ratio of the average optical power of the highest PAM level (P3) to the average power of the lowest level (P0), measured on the PRBS13Q or SSPRQ test pattern:

OER = P3 / P0
UnitFormulaDirection
RATioP3 / P0 (linear)higher is better
DECibel10 x log10(P3 / P0)higher is better
PERCent100 x (P0 / P3) = 100 / ratiolower is better

Conversions between the units:

dB = 10 x log10(ratio)
ratio = 10^(dB/10)
percent = 100 / ratio = 100 / 10^(dB/10)

For example, OER = 3.0 dB equals a linear ratio of 2.0 and a percent value of 50%. Note that RATio and DECibel increase with better extinction, while PERCent decreases.

{DECibel | PERCent | RATio}

Return Value
