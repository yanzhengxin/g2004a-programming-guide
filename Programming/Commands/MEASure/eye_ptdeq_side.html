:MEASure:EYE:PTDeq:SIDe

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PTDeq:SIDe {LEFT | RIGHt}

Query Syntax

:MEASure:EYE:PTDeq:SIDe?

Description

Selects the side of the waveform on which to perform the Partial TDECQ measurement (:MEASure:EYE:PTDeq).

Parameters

{LEFT | RIGHt}

Return Value

Return TypeASCII enumeration string (str)
Typical Return Value{LEFT | RIGH}
