:MEASure:EYE:TTIMe:TRANsition

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:TTIMe:TRANsition {RISing | FALLing | SLOWest}

Query Syntax

:MEASure:EYE:TTIMe:TRANsition?

Description

Selects a transition time measurement (:MEASure:EYE:TTIMe) based on the average rising edge, average falling edge, or the slowest edge.

Parameters

{RISing | FALLing | SLOWest}

Return Value

Return TypeASCII enumeration string (str)
Typical Return Value{RIS | FALL | SLOW}

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:TTIMe:SOURce FUNC2
:MEASure:EYE:TTIMe:TRANsition RISing
:MEASure:EYE:TTIMe:TRANsition?
:MEASure:EYE:TTIMe
:MEASure:EYE:TTIMe?
:MEASure:EYE:TTIMe:TRANsition FALLing
