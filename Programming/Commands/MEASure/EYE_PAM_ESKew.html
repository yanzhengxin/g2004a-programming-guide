:MEASure:EYE:PAM:ESKew

Query Syntax

:MEASure:EYE:PAM:ESKew?

Description

Returns Eye mode's PAM4 Eye Skews measurement where the skew (seconds or UI) of an eye is measured on a PAM4 signal.

Return TypeASCII float (s)
Typical Return Value1.20E-12
