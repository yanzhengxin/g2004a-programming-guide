Command Syntax

:MEASure:PAM:AMPLitude:UNITs {AMPLitude | PERCent}

Description

Sets the amplitude units for PAM4 level and level RMS (thickness) measurements.
The following measurements are affected by this setting:

Eye Mode
◆PAM Levels (:EYE:PAM:LEVel)
◆PAM Levels RMS (:EYE:PAM:RMS)
◆PAM Eye Levels (:EYE:PAM:ELEVel)
◆PAM Eye Heights (:EYE:PAM:EHeight)

Parameters

{AMPLitude | PERCent}
