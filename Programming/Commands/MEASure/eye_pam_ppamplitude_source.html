Command Syntax

:MEASure:EYE:PAM:PPAMplitude:SOURce

Query Syntax

:MEASure:EYE:PAM:PPAMplitude:SOURce?

Description

Selects the source waveform on which to perform the :MEASure:EYE:PAM:PPAMplitude measurement.

Return Value

Return TypeASCII waveform source string (str)
Typical Return ValueFUNC1

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:PAM:PPAMplitude:SOURce1 FUNC2
