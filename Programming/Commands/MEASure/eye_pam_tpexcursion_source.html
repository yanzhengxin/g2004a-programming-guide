Command Syntax

:MEASure:EYE:PAM:TPEXcursion:SOURce

Query Syntax

:MEASure:EYE:PAM:TPEXcursion:SOURce?

Description

Selects the source waveform on which to perform the Transmitter Power Excursion measurement for PAM4 signals. The source must be an eye diagram.

Return Value

Return TypeASCII waveform source string (str)
Typical Return ValueFUNC1

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:PAM:TPEXcursion:SOURce1 FUNC2
:MEASure:EYE:PAM:TPEXcursion:UNITs WATT
