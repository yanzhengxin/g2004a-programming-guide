:MEASure:EYE:PAM:ELEVel:EYE

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:ELEVel:EYE EYE{0:2}

Description

This command allows you to select an eye on PAM4 waveforms on which to perform the :MEASure:EYE:PAM:ELEVel measurement.

Parameters

EYE{0:2}

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:PAM:ELEVel:SOURce FUNC1
:MEASure:EYE:PAM:ELEVel:EYE EYE0
:MEASure:EYE:PAM:ELEVel:EYE?
:MEASure:EYE:PAM:ELEVel
:MEASure:EYE:PAM:ELEVel?
:MEASure:EYE:PAM:ELEVel:EYE EYE1
:MEASure:EYE:PAM:ELEVel:EYE?
:MEASure:EYE:PAM:ELEVel
:MEASure:EYE:PAM:ELEVel?
:MEASure:EYE:PAM:ELEVel:EYE EYE2
:MEASure:EYE:PAM:ELEVel:EYE?
:MEASure:EYE:PAM:ELEVel
