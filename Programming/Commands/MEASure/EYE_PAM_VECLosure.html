Command Syntax

:MEASure:EYE:PAM:VECLosure

Query Syntax

:MEASure:EYE:PAM:VECLosure?

Description

Returns the PAM4 Vertical Eye Closure measurements (VEC) located in the Eye Mode Results measurement results. Displays the measurement if it is not already shown on the table. The query form of the command returns the measured value.

Return Value

Return TypeASCII float (dB)
Typical Return Value2.2
