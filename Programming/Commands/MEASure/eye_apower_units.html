:MEASure:EYE:APOWer:UNITs

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:APOWer:UNITs {WATT | DBM}

Query Syntax

:MEASure:EYE:APOWer:UNITs?

Description

Selects the units of measurement for the average power measurement (APOWer).

Unit Conversion

The WATT and DBM settings express the same optical power in two different units. WATT is the linear power in watts, and DBM is the logarithmic power in dBm (decibels relative to 1 mW):

dBm = 10 x log10(P / 1 mW) = 10 x log10(P x 1000) [P in W]
P (W) = 10^(dBm / 10) / 1000

Equivalently, using the two conversion directions:

WATT -> DBM: dBm = 10 x log10(W) + 30
DBM -> WATT: W = 10^(dBm / 10 - 3)
dBmWatt (W)Milliwatt (mW)
-30 dBm1 uW0.001 mW
-20 dBm10 uW0.01 mW
-10 dBm100 uW0.1 mW
0 dBm1 mW1 mW
+10 dBm10 mW10 mW
+20 dBm100 mW100 mW
+30 dBm1 W1000 mW

Note: dBm is a logarithmic scale relative to 1 mW — every +10 dB multiplies the power by 10, and every -10 dB divides it by 10. A 0 dBm reading equals 1 mW.
