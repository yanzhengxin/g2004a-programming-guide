:MEASure:EYE:APOWer:SOURce

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:APOWer:SOURce CHANnel{1}{A|B|C|D}

Query Syntax

:MEASure:EYE:APOWer:SOURce?

Description

Selects the source waveform on which to perform the APOWer measurement.

Parameters

CHANnel{1}{A|B|C|D}

Return Value

Return TypeASCII waveform source string (str)
Typical Return ValueCHAN1A

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:APOWer:SOURce CHAN1B
:MEASure:EYE:APOWer:UNITs DBM
:MEASure:EYE:APOWer:UNITs?
:MEASure:EYE:APOWer
:MEASure:EYE:APOWer?
:MEASure:EYE:APOWer:UNITs WATT
:MEASure:EYE:APOWer:UNITs?
:MEASure:EYE:APOWer
:MEASure:EYE:APOWer?
