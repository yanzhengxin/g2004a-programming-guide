:MEASure:EYE:PAM:LEVel:SOURce

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:LEVel:SOURce {CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Query Syntax

:MEASure:EYE:PAM:LEVel:SOURce?

Description

Selects the source waveform on which to perform the LEVel measurement for PAM4 signals.

Parameters

{CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Return Value

Return TypeASCII waveform source string (str)
Typical Return ValueFUNC1
