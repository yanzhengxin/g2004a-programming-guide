:MEASure:EYE:PAM:ESKew:EYE

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:ESKew:EYE EYE{0:2}

Query Syntax

:MEASure:EYE:PAM:ESKew:EYE?

Description

This command allows you to select an eye on PAM4 signals on which to perform the :MEASure:EYE:PAM:ESKew measurement.

Parameters

EYE{0:2}

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:PAM:ESKew:SOURce FUNC1
:MEASure:EYE:PAM:ESKew:EYE EYE0
:MEASure:EYE:PAM:ESKew:EYE?
:MEASure:EYE:PAM:ESKew
:MEASure:EYE:PAM:ESKew?
:MEASure:EYE:PAM:ESKew:EYE EYE1
:MEASure:EYE:PAM:ESKew:EYE?
:MEASure:EYE:PAM:ESKew
:MEASure:EYE:PAM:ESKew?
:MEASure:EYE:PAM:ESKew:EYE EYE2
:MEASure:EYE:PAM:ESKew:EYE?
:MEASure:EYE:PAM:ESKew
:MEASure:EYE:PAM:ESKew?
