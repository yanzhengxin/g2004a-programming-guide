:MEASure:EYE:PAM:RMS:LEVel

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:RMS:LEVel LEVel{0:3}

Query Syntax

:MEASure:EYE:PAM:RMS:LEVel?

Description

Selects the eye diagram's level on which to perform the :MEASure:EYE:PAM:RMS measurement.

Parameters

LEVel{0:3}

:MEASure:EYE:LIST:CLEar
