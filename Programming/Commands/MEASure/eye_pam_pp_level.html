:MEASure:EYE:PAM:PP:LEVel

Home › Command Reference › MEASure Subsystem

Command Syntax

:MEASure:EYE:PAM:PP:LEVel LEVel{0:3}

Query Syntax

:MEASure:EYE:PAM:PP:LEVel?

Description

Selects the eye diagram's level on which to perform the :PP measurement.

Parameters

LEVel{0:3}

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:PAM:PP:SOURce FUNC2
:MEASure:EYE:PAM:PP:LEVel LEVel0

:MEASure:EYE:PAM:PP?

:MEASure:EYE:PAM:PP:LEVel?
:MEASure:EYE:PAM:PP
