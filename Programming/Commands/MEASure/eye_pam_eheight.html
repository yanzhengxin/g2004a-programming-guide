Command Syntax

:MEASure:EYE:PAM:EHEight

Query Syntax

:MEASure:EYE:PAM:EHEight?

Description

Returns Eye/Mask mode's PAM4 Eye Height measurement for the selected eye.

Return Value

Return TypeASCII float (amplitude unit follows source)
Typical Return Value1.00E-1
