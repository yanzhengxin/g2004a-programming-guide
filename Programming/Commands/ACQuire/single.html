Command Syntax

:ACQuire:SINGle

Description

If the acquisition is in Run mode, the current acquisition sweep is completed and the acquisition is stopped after the last data point is acquired.If the acquisition is in Stop mode, a single waveform acquisition is performed. .While at least one input channel is turned on.

Programming Example

:ACQuire:CDISplay
:ACQuire:SINGle
*OPC?
:MEASure:EYE:TDEQ:SOURce FUNC1
:MEASure:EYE:TDEQ
:MEASure:EYE:TDEQ?
*OPC?
