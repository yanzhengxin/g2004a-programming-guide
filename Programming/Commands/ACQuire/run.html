Command Syntax

:ACQuire:RUN

Description

Starts continuous data acquisition on all selected channels.While at least one input channel is turned on.If you want to run a number of patterns,, use an acquisition limit test (:LTESt:ACQuire:STATe) to set up the conditions and then use the :ACQuire:RUN command to start the test.

Programming Example

:ACQuire:CDISplay
:ACQuire:RUN
*OPC?
:MEASure:EYE:TDEQ:SOURce FUNC1
:MEASure:EYE:TDEQ
:MEASure:EYE:TDEQ?
*OPC?
