:CHANnel{1}{A|B|C|D}:BANDwidth

Command Syntax

:CHANnel{1}{A|B|C|D}:BANDwidth {BANDwidth{1:16}}

Query Syntax

:CHANnel{1}{A|B|C|D}:BANDwidth?

Description

Selects the sampler bandwidth (in Hz) of an electrical or optical channel. There can be up to 16 supported sampler bandwidth settings, depending on the module. The sampler bandwidth affects the width of the sampling pulse used by the instrument. Wider bandwidths allow the instrument to respond to fast changes in a waveform. The increased bandwidth yields the highest measurement fidelity. Narrow bandwidth offers the best sensitivity by reducing the noise on the input waveform while still maintaining good frequency response.

Parameters

{BANDwidth{1:16}}
