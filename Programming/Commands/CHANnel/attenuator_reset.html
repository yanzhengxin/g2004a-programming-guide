Command Syntax

:CHANnel{1}{A|B|C|D}:ATTenuator:RESet

Description

Resets the attenuation compensation factor to 0 (1:1).

Programming Example

:CHAN1B:ATTenuator:STATe ON
:CHAN1B:ATTenuator:STATe?
:CHAN1B:ATTenuator:DECibels 3.00
:CHAN1B:ATTenuator:DECibels?
:CHAN1B:ATTenuator:RESet
:CHAN1B:ATTenuator:DECibels?
:CHAN1B:ATTenuator:DECibels -3.00
:CHAN1B:ATTenuator:DECibels?
:CHAN1B:ATTenuator:RESet
:CHAN1B:ATTenuator:DECibels?
:CHAN1B:ATTenuator:STATe OFF
:CHAN1B:ATTenuator:STATe?
