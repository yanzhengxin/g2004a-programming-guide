:CHANnel{1}{A|B|C|D}:SIRC:FBANdwidth

Home › Command Reference › CHANnel Subsystem

Command Syntax

:CHANnel{1}{A|B|C|D}:SIRC:FBANdwidth <bandwidth>

Query Syntax

:CHANnel{1}{A|B|C|D}:SIRC:FBANdwidth?

Description

SIRC data is created for specific filter rates and 3 dB bandwidths. Once the SIRC data has been loaded, use this command to select the 3 dB bandwidth.<bandwidth> is a double.

Parameters

<bandwidth>

Return Value

Return TypeASCII float
Typical Return Value5.3125E+10
