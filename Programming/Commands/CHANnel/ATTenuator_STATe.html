Command Syntax

:CHANnel{1}{A|B|C|D}:ATTenuator:STATe {OFF | ON}

Query Syntax

:CHANnel{1}{A|B|C|D}:ATTenuator:STATe?

Description

Turns on and off compensation for external attenuator in the test setup. This allows G2004 to report measurement values as if the measurements were made before the attenuator rather than at the oscilloscope's channel input.

Parameters

{OFF | ON}

Return Value

Return TypeASCII integer (int, boolean)
Typical Return Value1 (on) or 0 (off)
