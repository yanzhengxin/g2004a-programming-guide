:CHANnel{1}{A|B|C|D}:WAVelength

Command Syntax

:CHANnel{1}{A|B|C|D}:WAVelength { WAVelength{1}}

Query Syntax

:CHANnel{1}{A|B|C|D}:WAVelength?

Description

Selects the calibrated wavelength for measurements.
The module will have one factory calibration for each factory-defined wavelength. The USER argument is only valid if this user-defined calibration has been performed.

Parameters

{ WAVelength{1}}

Return Value

Return TypeASCII enumeration string (str)
Typical Return ValueWAV1
