:CHANnel{1}{A|B|C|D}:TRANsducer:OFFSet

Home › Command Reference › CHANnel Subsystem

Command Syntax

:CHANnel{1}{A|B|C|D}:TRANsducer:OFFSet <offset>

Query Syntax

:CHANnel{1}{A|B|C|D}:TRANsducer:OFFSet?

Description

Enters or queries the offset setting for an external transducer. The measurement units of the offset are the same as the measurement units specified with the :CHANnel:TRANsducer:UNITs command

Parameters

<offset>
