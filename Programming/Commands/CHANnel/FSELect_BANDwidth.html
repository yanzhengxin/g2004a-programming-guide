:CHANnel{1}{A|B|C|D}:FSELect:BANDwidth

Home › Command Reference › CHANnel Subsystem

Command Syntax

:CHANnel{1}{A|B|C|D}:FSELect:BANDwidth <bandwidth_in_Hertz>

Query Syntax

:CHANnel{1}{A|B|C|D}:FSELect:BANDwidth?

Description

For optical channels, selects or queries the reference filter by 3 dB bandwidth. The channel will use the reference filter that is closest to the requested bandwidth.

Parameters

<bandwidth_in_Hertz>
