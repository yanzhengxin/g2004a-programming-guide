:CHANnel{1}{A|B|C|D}:ATTenuator:DECibels

Command Syntax

:CHANnel{1}{A|B|C|D}:ATTenuator:DECibels <attenuation>

Query Syntax

:CHANnel{1}{A|B|C|D}:ATTenuator:DECibels?

Description

Enters or queries an attenuation compensation factor in decibels. Enter attenuation as a positive value.Gain is implied when you enter negative decibel values.

Parameters

<attenuation>
