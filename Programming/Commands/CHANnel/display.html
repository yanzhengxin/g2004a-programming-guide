:CHANnel{1}{A|B|C|D}:DISPlay

Home › Command Reference › CHANnel Subsystem

Command Syntax

:CHANnel{1}{A|B|C|D}:DISPlay {ON | OFF | 1 | 0}

Query Syntax

:CHANnel{1}{A|B|C|D}:DISPlay?

Description

Turns the display of the specified channel on or off.

Parameters

{ON | OFF | 1 | 0}

Return Value

Return TypeASCII integer (int, boolean)
Typical Return Value1 (on) or 0 (off)

Programming Example

:FUNCtion1:DISPlay ON
:CHANnel1A:DISPlay ON
:FUNCtion1:DISPlay OFF
:CHANnel1A:DISPlay OFF
:FUNCtion1:DISPlay ON
:CHANnel1A:DISPlay ON
