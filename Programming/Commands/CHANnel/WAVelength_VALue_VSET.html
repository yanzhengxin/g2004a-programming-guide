Query Syntax

:CHANnel{1}{A|B|C|D}:WAVelength:VALue:VSET?

Description

Queries a list of available wavelengths in meters for the selected optical channel. For example,
"1.310E-6"

Return Value

Return TypeASCII string (str)
Typical Return Value”1.310E-6“
