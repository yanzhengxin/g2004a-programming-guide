Command Syntax

:CHANnel{1}{A|B|C|D}:FILTer {ON | OFF | 1 | 0}

Query Syntax

:CHANnel{1}{A|B|C|D}:FILTer?

Description

Turn on or off the use of reference filters on an optical channels for compliance testing.

Parameters

{ON | OFF | 1 | 0}

Return Value

Return TypeASCII integer (int, boolean)
Typical Return Value1 (on) or 0 (off)
