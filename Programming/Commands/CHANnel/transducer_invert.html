:CHANnel{1}{A|B|C|D}:TRANsducer:INVert

Home › Command Reference › CHANnel Subsystem

Command Syntax

:CHANnel{1}{A|B|C|D}:TRANsducer:INVert {OFF | ON}

Query Syntax

:CHANnel{1}{A|B|C|D}:TRANsducer:INVert?

Description

Setting inversion ON indicates negative transducer gain. The default setting is OFF. With inversion on, the External Hardware Setup dialog shows negative gain (for example, −2.3 V/V). however a query of the :CHANnel:TRANsducer:GAIN command returns a positive value.

Parameters

{OFF | ON}

Return Value

Return TypeASCII integer (int, boolean)
Typical Return Value1 (on) or 0 (off)

Programming Example

:CHAN1B:TRANsducer:STATe ON
:CHAN1B:TRANsducer:STATe?
:CHAN1B:TRANsducer:INVert ON
:CHAN1B:TRANsducer:INVert?
:CHAN1B:TRANsducer:UNITs WATT
:CHAN1B:TRANsducer:UNITs?
:CHAN1B:TRANsducer:GAIN 1.000
:CHAN1B:TRANsducer:GAIN?
:CHAN1B:TRANsducer:OFFSet 2.000E-6
:CHAN1B:TRANsducer:OFFSet?
:CHAN1B:TRANsducer:INVert OFF
:CHAN1B:TRANsducer:INVert?
:CHAN1B:TRANsducer:GAIN 2.000
:CHAN1B:TRANsducer:GAIN?
:CHAN1B:TRANsducer:OFFSet 6.000E-6
:CHAN1B:TRANsducer:OFFSet?
:CHAN1B:TRANsducer:STATe OFF
:CHAN1B:TRANsducer:STATe?
