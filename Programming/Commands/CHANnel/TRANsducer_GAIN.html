:CHANnel{1}{A|B|C|D}:TRANsducer:GAIN

Home › Command Reference › CHANnel Subsystem

Command Syntax

:CHANnel{1}{A|B|C|D}:TRANsducer:GAIN <gain>

Query Syntax

:CHANnel{1}{A|B|C|D}:TRANsducer:GAIN?

Description

Enters or queries the gain setting for an external transducer.A query of :CHANnel:TRANsducer:GAIN? always returns a positive value even if negative transducer gain is indicated with the :CHANnel:TRANsducer:INVert command.

Parameters

<gain>
