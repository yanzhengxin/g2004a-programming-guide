Command Syntax

:CHANnel{1}{A|B|C|D}:WAVelength:VALue <wavelength-in-meters>

Description

On optical channels,enters a calibrated wavelenth (in meters) for measurements. The channel will use the wavelength that is closest to the requested number.<wavelength> is a double
