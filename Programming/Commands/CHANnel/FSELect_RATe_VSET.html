Query Syntax

:CHANnel{1}{A|B|C|D}:FSELect:RATe:VSET?

Description

Queries a list of available reference filters in symbols-per-second (Bd) for the selected channel.The reference filter values (b/2) in the returned list are in the same order as they are listed in the Reference Filter field
