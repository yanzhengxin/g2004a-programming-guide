:CHANnel{1}{A|B|C|D}:ATTenuator:RATio

Home › Command Reference › CHANnel Subsystem

Command Syntax

:CHANnel{1}{A|B|C|D}:ATTenuator:RATio <ratio>

Query Syntax

:CHANnel{1}{A|B|C|D}:ATTenuator:RATio?

Description

Enters or queries an attenuation compensation factor as a ratio. Use the :CHANnel:ATTenuator:DECibels command to enter a factor based on decibels. Use the :CHANnel:ATTenuator:STATe command to turn attenuation compensation on and off. To reset the attenuation factor to 0 (1:1), use the :CHANnel:ATTenuator:RESet command.

Parameters

<ratio>

Programming Example

:CHAN1B:ATTenuator:STATe ON
:CHAN1B:ATTenuator:STATe?
:CHAN1B:ATTenuator:RATio 2.000
:CHAN1B:ATTenuator:RATio?
:CHAN1B:ATTenuator:RESet
:CHAN1B:ATTenuator:RATio?
:CHAN1B:ATTenuator:RATio 5.000
:CHAN1B:ATTenuator:RATio?
:CHAN1B:ATTenuator:RESet
:CHAN1B:ATTenuator:RATio?
:CHAN1B:ATTenuator:STATe OFF
:CHAN1B:ATTenuator:STATe?
