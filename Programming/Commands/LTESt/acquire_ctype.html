:LTESt:ACQuire:CTYPe

Home › Command Reference › LTESt Subsystem

Command Syntax

:LTESt:ACQuire:CTYPe {PATTerns}

Query Syntax

:LTESt:ACQuire:CTYPe?

Description

Selects the type of condition to base the acquisition limit tests "run until" condition. Use the :LTESt:ACQuire:STATe command to enable or disable acquisition limit tests. During the limit test, use the :MEASure:LTESt:ACQuire:COUNt? query to return the current count of patterns
• PATTerns
Runs the test until the number of patterns specified by the :PATTerns child command occurs. This option is only available if Acquire Entire Pattern is on (:ACQuire:EPATtern command is on).

Parameters

{PATTerns}

Return Value

Typical Return ValueLTESt

Programming Example

:LTESt:ACQuire:STATe ON
:LTESt:ACQuire:STATe?
:LTESt:ACQuire:CTYPe PATTerns
:LTESt:ACQuire:CTYPe?
:LTESt:ACQuire:CTYPe:PATTerns 10
:LTESt:ACQuire:CTYPe:PATTerns?

Related Commands
