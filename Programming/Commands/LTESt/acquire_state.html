:LTESt:ACQuire:STATe

Home › Command Reference › LTESt Subsystem

Command Syntax

:LTESt:ACQuire:STATe {ON | OFF | 1 | 0}

Query Syntax

:LTESt:ACQuire:STATe?

Description

Enables acquisition limit testing. The actual test is started by placing the G2004A software in run mode (:ACQuire:RUN). You must use the :ACQuire:RUN command to start continuous sweeps and so begin the test

Parameters

{ON | OFF | 1 | 0}

Return Value

Typical Return ValueLTESt

Programming Example

:LTESt:ACQuire:CTYPe:PATTerns 3
:LTESt:ACQuire:CTYPe:PATTerns?
:LTESt:ACQuire:STATe ON
:LTESt:ACQuire:STATe?
:ACQuire:RUN
*OPC?
