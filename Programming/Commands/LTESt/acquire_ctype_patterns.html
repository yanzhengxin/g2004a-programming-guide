:LTESt:ACQuire:CTYPe:PATTerns

Home › Command Reference › LTESt Subsystem

Command Syntax

:LTESt:ACQuire:CTYPe:PATTerns <number>

Query Syntax

:LTESt:ACQuire:CTYPe:PATTerns?

Description

Enters the number of patterns required to stop an acquisition limit test that is based on patterns. Use the :LTESt:ACQuire:CTYPe command to select to test based on patterns.

Parameters

<number>

Return Value

Typical Return ValueLTESt

Programming Example

:LTESt:ACQuire:CTYPe:PATTerns 3
:LTESt:ACQuire:CTYPe:PATTerns?
:LTESt:ACQuire:STATe ON
:LTESt:ACQuire:STATe?
:ACQuire:RUN
*OPC?
:MEASure:LTESt:ACQuire:COUNt?
