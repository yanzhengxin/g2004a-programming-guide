:DISPlay:UISCaling

Home › Command Reference › DISPlay Subsystem

Command Syntax

:DISPlay:UISCaling {UNSCaled | MAXimized | ZMAXimized}

Query Syntax

:DISPlay:UISCaling?

Description

Sets the physical size that the application requires on the display. Choices are the default unscaled (UNSCaled ), full screen (MAXimized), full-screen zoomed (ZMAXimized).

Parameters

{UNSCaled | MAXimized | ZMAXimized}

Return Value

Return TypeASCII enumeration string (str)
Typical Return ValueUNSCaled
