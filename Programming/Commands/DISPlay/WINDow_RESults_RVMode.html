:DISPlay:WINDow:RESults:RVMode

Command Syntax

:DISPlay:WINDow:RESults:RVMode {GRID | TILE}

Query Syntax

:DISPlay:WINDow:RESults:RVMode?

Description

Displays the data in G2004 and Eyemode's Results measurements pane in either tiled or grid view.

Parameters

{GRID | TILE}

Return Value

Return TypeASCII enumeration string (str)
Typical Return ValueGRID
