:DISPlay:WINDow:RESults:RVMode

Home › Command Reference › DISPlay Subsystem

Command Syntax

:DISPlay:WINDow:RESults:RVMode {GRID | TILE}

Query Syntax

:DISPlay:WINDow:RESults:RVMode?

Description

Displays the data in G2004 and Eyemode's Results measurements pane in either tiled or grid view.

Parameters

{GRID | TILE}

Return Value

Return TypeASCII enumeration string (str)
Typical Return ValueGRID

Programming Example

:MEASure:EYE:LIST:CLEar
:MEASure:EYE:APOWer:SOURce FUNC1
:MEASure:EYE:APOWer:UNITs DBM
:MEASure:EYE:APOWer
:MEASure:EYE:APOWer?
:DISPlay:WINDow:RESults:RVMode GRID
:DISPlay:WINDow:RESults:RVMode TILE
:DISPlay:WINDow:RESults:RVMode GRID
