:DISPlay:TSMode

Home › Command Reference › DISPlay Subsystem

Command Syntax

:DISPlay:TSMode {MINimized | HSIZe | FSIZe}

Query Syntax

:DISPlay:TSMode?

Description

Sets the height of all displayed secondary panels that are shown below the waveform gratical. Examples of secondary panels include the measurement Results,. These panels can be hidden (MINimized), full vertical height (FSIZe), or half vertical height (HSIZe).

Parameters

{MINimized | HSIZe | FSIZe}

Return Value

Return TypeASCII enumeration string (str)
Typical Return ValueMINimized
