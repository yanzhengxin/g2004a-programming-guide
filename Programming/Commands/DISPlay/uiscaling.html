:DISPlay:UISCaling

Home › Command Reference › DISPlay Subsystem

Command Syntax

:DISPlay:UISCaling {UNSCaled | MAXimized }

Query Syntax

:DISPlay:UISCaling?

Description

Sets the physical size that the application requires on the display. Choices are the default unscaled (UNSCaled ), full screen (MAXimized).

Parameters

{UNSCaled | MAXimized }

Return Value

Return TypeASCII enumeration string (str)
Typical Return ValueUNSCaled

Programming Example

:DISPlay:UISCaling UNSCaled
:DISPlay:UISCaling MAXimized
:DISPlay:UISCaling UNSCaled
