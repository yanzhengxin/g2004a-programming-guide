Command Syntax

:DISPlay:WINDow:TIME{1}:ZSIGnal

Query Syntax

:DISPlay:WINDow:TIME{1}:ZSIGnal?

Description

When a Waveform content window is displayed in zoom tiled mode and there are multiple displayed waveforms, selects a waveform to display in the graticule area. Channel and differential channel waveforms can be viewed in a Waveform content window.

Return Value

Return TypeASCII waveform source string (str)
Typical Return ValueCHAN1A
