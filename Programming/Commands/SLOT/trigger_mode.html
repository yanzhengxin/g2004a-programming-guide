Query Syntax

:SLOT{1}:TRIGger:MODe?

Description

Returns the trigger mode of a DCA-M product. The value returned is always CLOCk.

Return Value

Return TypeASCII enumeration string (str)
Typical Return ValueCLOCk

Programming Example

:SLOT1:TRIGger:SOURce FPANel
:SLOT1:TRIGger:MODe?
:SLOT1:TRIGger:SOURce CRECovery
:SLOT1:TRIGger:MODe?
