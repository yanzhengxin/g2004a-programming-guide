:SLOT{1}:TRIGger:SRATe

Home › Command Reference › SLOT Subsystem

Command Syntax

:SLOT{1}:TRIGger:SRATe <rate>

Query Syntax

:SLOT{1}:TRIGger:SRATe?

Description

Enter the symbol-rate of the trigger source when using pattern lock. 53.125 106.25 113.4375

Parameters

<rate>

Return Value

Return TypeASCII float
Typical Return Value1.0625E+11

Programming Example

:SLOT1:TRIGger:SOURce FPANel
:SLOT1:TRIGger:SOURce?
:SLOT1:TRIGger:DCDRatio SUB8
:SLOT1:TRIGger:DCDRatio?
:SLOT1:TRIGger:SRATe 5.3125000E+10
:SLOT1:TRIGger:SRATe?
