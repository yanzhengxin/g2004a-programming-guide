:SLOT{1}:TRIGger:DCDRatio

Home › Command Reference › SLOT Subsystem

Command Syntax

:SLOT{1}:TRIGger:DCDRatio {SUB2|SUB4|SUB8|SUB16|SUB32}

Query Syntax

:SLOT{1}:TRIGger:DCDRatio?

Description

Enters the trigger-divide ratio. In some situations, you may need to enter a trigger divide ratio for a trigger that is a divided rate from the data rate.
| Rate | Argument |
| 1:2 (Sub-Rate) | SUB2 |
| 1:4 (Sub-Rate) | SUB4 |
| 1:8 (Sub-Rate) | SUB8 |
| 1:16 (Sub-Rate) | SUB16 |
| 1:32 (Sub-Rate) | SUB32 |

Parameters

{SUB2|SUB4|SUB8|SUB16|SUB32}

Return Value

Return TypeASCII enumeration string (str)
Typical Return Value{SUB2|SUB4|SUB8|SUB16|SUB32}

Programming Example

:SLOT1:TRIGger:DCDRatio SUB8
:SLOT1:TRIGger:DCDRatio?
