:SLOT{1}:TRIGger:SOURce

Home › Command Reference › SLOT Subsystem

Command Syntax

:SLOT{1}:TRIGger:SOURce {FPANel }

Query Syntax

:SLOT{1}:TRIGger:SOURce?

Description

Select the trigger input of the G2004 product's optical sampling oscilloscope.
• Front Panel. The DCA-M is being triggered from a clock that is input to theDCA-M's front-panel Clock In connector.
• Free Run. The DCA-M is triggered as soon as the trigger is armed, without having to provide an external trigger.

Parameters

{FPANel }

Return Value

Return TypeASCII enumeration string (str)
Typical Return ValueFPANel

Programming Example

:SLOT1:TRIGger:SOURce FPANel
:SLOT1:TRIGger:SOURce?
