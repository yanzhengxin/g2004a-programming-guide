:SLOT{1}:TRIGger:PLENgth

Home › Command Reference › SLOT Subsystem

Command Syntax

:SLOT{1}:TRIGger:PLENgth <bits>

Query Syntax

:SLOT{1}:TRIGger:PLENgth?

Description

When using pattern lock use this command to enter or read the symbol rate of the trigger source.

Parameters

<bits>

Return Value

Return TypeASCII integer (int)
Typical Return Value65535

Programming Example

:SLOT1:TRIGger:DCDRatio SUB8
:SLOT1:TRIGger:DCDRatio?
:SLOT1:TRIGger:SRATe 1.0625000E+11
:SLOT1:TRIGger:SRATe?
:SLOT1:TRIGger:PLENgth 65535
:SLOT1:TRIGger:PLENgth?
