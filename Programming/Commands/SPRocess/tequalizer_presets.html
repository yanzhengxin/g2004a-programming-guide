Description

Loads a previously saved a preset for the TDECQ Equalizer operator The preset configures the operator to your saved settings.

TDECQ Equalizer Presets

The :SPRocess:TEQualizer:PRESets command loads a saved preset that configures the TDECQ reference equalizer. Each preset applies the reference receiver and equalizer settings defined by a specific IEEE 802.3 Ethernet PAM4 standard.

The presets differ primarily in the signaling rate (baud rate) they target, which in turn determines the reference receiver bandwidth and the feed-forward equalizer (FFE) tap configuration. The baud rate itself is determined by the acquired signal and the clock recovery, not by the preset.

IEEE 802.3cd802.3cd (2018)26.5625 / 53.125 GBd50G / 100G per lane
IEEE 802.3bs802.3bs (2017)26.5625 / 53.125 GBd50G / 100G per lane
IEEE 802.3bs Amended802.3bs (amended)26.5625 / 53.125 GBd50G / 100G per lane
IEEE 802.3dj Draft 2.0802.3dj (draft)106.25 GBd200G per lane

Key Differences

  • Baud rate: the dominant difference. PAM4 baud rates double through the standards: 26.5625 GBd (50G/lane), 53.125 GBd (100G/lane, e.g. 400GBASE-DR4), and 106.25 GBd (200G/lane). IEEE 802.3bs and 802.3cd cover 26.5625 GBd and 53.125 GBd, while IEEE 802.3dj covers 106.25 GBd. Each doubling halves the unit interval: 37.65 ps, 18.82 ps, and 9.41 ps respectively.
  • Reference receiver bandwidth: a Bessel-Thomson filter whose 3 dB bandwidth is defined as a fraction of the baud rate (typically ≈ 0.75 × baud), so it scales automatically with the measured baud rate. A single preset therefore covers each standard across its baud rates.
  • Equalizer: a feed-forward equalizer (FFE); the tap count, main-tap position, and tap limits are defined per standard and are refined in later standards.
  • Target SER: the symbol error ratio used for the TDECQ noise threshold, typically 4.8 × 10-4.

Select the preset that matches the transmitter under test: use IEEE 802.3cd or IEEE 802.3bs for 50G/lane and 100G/lane optics, and IEEE 802.3dj Draft 2.0 for 200G/lane (800G / 1.6T) optics.

<string>
