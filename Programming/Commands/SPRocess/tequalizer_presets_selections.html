Query Syntax

:SPRocess:TEQualizer:PRESets:SELections?

Description

Returns a string which is a comma-separated list of all saved presets for the TDECQ Equalizer operator. Use the PRESet command to load one of these presets.

Return Value

Return TypeASCII enumeration string (str)
Typical Return Value<preset name>

Related Commands

  • :SPRocess{1:4}:TEQualizer:PRESets
