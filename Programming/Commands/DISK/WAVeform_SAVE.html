Command Syntax

:DISK:WAVeform:SAVE

Description

Saves a single-valued waveform to a file. Use the :DISK:WAVeform:FNAMe command to specify the file name and the :DISK:WAVeform:SAVE:FTYPe command to specify one of the following two waveform file types:
Pattern format waveform (.csv)
Y-value format waveform (.txt)
