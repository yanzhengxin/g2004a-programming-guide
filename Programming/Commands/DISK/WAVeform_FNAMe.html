:DISK:WAVeform:FNAMe

Home › Command Reference › DISK Subsystem

Command Syntax

:DISK:WAVeform:FNAMe "<path substitution string>\subfolder\filename"

Query Syntax

:DISK:WAVeform:FNAMe?

Description

Save a WAVeform file.
◆ "<path substitution string> is a string that expands into a specific file path. For example, %USER_DATA_DIR%.
◆ "subfolder" is an optional path folder. For example, \Waveforms.
◆ "filename.extension" is a string with the filename and extension.

Parameters

"<path substitution string>\subfolder\filename"

Return Value

Return TypeASCII string (str)
Typical Return Value"%USER_DATA_DIR%\Waveforms\myfile"
