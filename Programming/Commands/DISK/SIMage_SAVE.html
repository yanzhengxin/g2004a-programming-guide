Command Syntax

:DISK:SIMage:SAVE

Description

Performs a screen capture of the G2004 GUI window and saves the image to the specified file name and extension that is specified with the :DISK:SIMage:FNAMe command. The filename extension selects the file's graphics format. To increment the automatic file number index, use the :DISK:SIMage:FNAMe:AUPDate command.
