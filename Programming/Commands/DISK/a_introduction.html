DISK Subsystem (Disk)

Home › Command Reference › DISK Subsystem

Saves waveforms, screen images, and setups to files, or recalls them from files.

Commands

  • :DISK:SIMage:FNAMe
  • :DISK:SIMage:FNAMe:AUPDate
  • :DISK:SIMage:SAVE
  • :DISK:WAVeform:FNAMe
  • :DISK:WAVeform:SAVE
  • :DISK:WAVeform:SAVE:FTYPe
  • :DISK:WAVeform:SAVE:SOURce
