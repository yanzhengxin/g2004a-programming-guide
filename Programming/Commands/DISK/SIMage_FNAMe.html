:DISK:SIMage:FNAMe

Home › Command Reference › DISK Subsystem

Command Syntax

:DISK:SIMage:FNAMe "<path substitution string>\subfolder\filename.extension"

Query Syntax

:DISK:SIMage:FNAMe?

Description

Save a screen image file.
"<path substitution string> is a string that expands into a specific file path. For example, %USER_DATA_DIR%.
"subfolder" is an optional path folder. For example, \Screen Images.
"filename.extension" is a string with the filename and extension.

Parameters

"<path substitution string>\subfolder\filename.extension"

Return Value

Return TypeASCII path string (str)
Typical Return ValueC:\Users\Public\Documents\G2004A\example.png
