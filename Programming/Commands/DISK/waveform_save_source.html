:DISK:WAVeform:SAVE:SOURce

Home › Command Reference › DISK Subsystem

Command Syntax

:DISK:WAVeform:SAVE:SOURce {CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Query Syntax

:DISK:WAVeform:SAVE:SOURce?

Description

Selects the source waveform for saving to a waveform file. Use :DISK:WAVeform:SAVE to actually save the file.

Parameters

{CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Return Value

Return TypeASCII string (source waveform identifier)
Typical Return ValueFUNC1

Programming Example

:DISK:WAVeform:FNAMe "C:\Users\admin\AppData\Local\Temp\g2004a_wave\Waveform_2026-11-13_1.csv"
:DISK:WAVeform:SAVE:SOURce CHAN1B
:DISK:WAVeform:SAVE
:DISK:WAVeform:FNAMe "C:\Users\admin\AppData\Local\Temp\g2004a_wave\Waveform_2026-11-13_2.csv"
:DISK:WAVeform:SAVE:SOURce FUNC2
:DISK:WAVeform:SAVE
