:DISK:WAVeform:SAVE:FTYPe

Home › Command Reference › DISK Subsystem

Command Syntax

:DISK:WAVeform:SAVE:FTYPe { WYValues | WPATtern }

Query Syntax

:DISK:WAVeform:SAVE:FTYPe?

Description

Selects the file format for saving a waveform to a file. The actual file can be saved using the :DISK:WAVeform:SAVE parent command or as a result of a acquisition limit test or a eye mask limit test. The appropriate file name extension is appended to the file name that is specified using the :DISK:WAVeform:FNAMe command.

Parameters

{ WYValues | WPATtern }

Return Value

Return TypeASCII string (str)
Typical Return ValueWINT
