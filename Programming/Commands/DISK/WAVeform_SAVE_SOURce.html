:DISK:WAVeform:SAVE:SOURce

Home › Command Reference › DISK Subsystem

Command Syntax

:DISK:WAVeform:SAVE:SOURce {CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Query Syntax

:DISK:WAVeform:SAVE:SOURce?

Description

Selects the source waveform for saving to a waveform file. Use :DISK:WAVeform:SAVE to actually save the file.

Parameters

{CHANnel{1}{A|B|C|D} | FUNCtion{1:4} }

Return Value

Return TypeASCII string (source waveform identifier)
Typical Return ValueCHAN1A
