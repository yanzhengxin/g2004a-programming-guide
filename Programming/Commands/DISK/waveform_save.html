Command Syntax

:DISK:WAVeform:SAVE

Description

Saves a single-valued waveform to a file. Use the :DISK:WAVeform:FNAMe command to specify the file name and the :DISK:WAVeform:SAVE:FTYPe command to specify one of the following two waveform file types:
• Pattern format waveform (.csv)
• Y-value format waveform (.txt)

Programming Example

:DISK:WAVeform:FNAMe "C:\Users\admin\AppData\Local\Temp\g2004a_wave\Waveform_2026-11-13_1.csv"
:DISK:WAVeform:SAVE:SOURce CHAN1B
:DISK:WAVeform:SAVE
:DISK:WAVeform:FNAMe "C:\Users\admin\AppData\Local\Temp\g2004a_wave\Waveform_2026-11-13_2.csv"
:DISK:WAVeform:SAVE:SOURce FUNC2
:DISK:WAVeform:SAVE
