:FUNCtion{1:4}:COLor

Home › Command Reference › FUNCtion Subsystem

Command Syntax

:FUNCtion{1:4}:COLor {TCOLor1 | TCOLor2 | … | TCOLor16}

Query Syntax

:FUNCtion{1:4}:COLor?

Description

Selects the color used to identify an operator's output waveform on the screen.

Parameters

{TCOLor1 | TCOLor2 | … | TCOLor16}

Return Value

Return TypeASCII enumeration string (str)
Typical Return ValueTCOLor1

Programming Example

:Function2:DISPlay ON
:Function1:DISPlay ON
:Function2:COLor TCOLor14
:Function1:COLor TCOLor2
:Function2:COLor TCOLor7
:FUNCtion2:COLor TCOLor6
