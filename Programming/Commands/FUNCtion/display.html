Command Syntax

:FUNCtion{1:4}:DISPlay {ON | OFF | 1 | 0}

Query Syntax

:FUNCtion{1:4}:DISPlay?

Description

Displays or hides the indicated function waveform.

Parameters

{ON | OFF | 1 | 0}

Return Value

Return TypeASCII integer (int, boolean)
Typical Return Value1 (on) or 0 (off)

Programming Example

:Function2:DISPlay ON
:Function1:DISPlay ON

:Function1:COLor TCOLor2
:Function2:COLor TCOLor7
